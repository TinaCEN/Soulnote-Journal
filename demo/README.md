# Soulnote Demo Gallery

这个文件夹包含了Soulnote项目的演示内容，展示了应用的各种功能。

## 功能演示

### 1. 情感分析海报
在 `output/` 文件夹中，你可以看到各种情感分析生成的海报：

- **快乐情感**: `poster_joy_*.png`
- **悲伤情感**: `poster_sadness_*.png`  
- **平静情感**: `poster_calm_*.png`
- **困惑情感**: `poster_confusion_*.png`
- **沉思情感**: `poster_contemplative_*.png`

### 2. 多种格式支持
每种情感海报都支持多种社交媒体格式：
- 标准格式（1080x1350）
- Instagram格式（1080x1080）
- 其他自定义尺寸

### 3. 演示模式特色

当没有配置API密钥时，应用自动运行在演示模式：

#### ✅ 完全可用的功能：
- 🎤 语音录制和播放
- 🔊 语音转文字（Speech-to-Text）
- 🎨 情感海报生成
- 📱 多种导出格式
- 💫 动画和交互效果
- 🌊 音频可视化

#### 🎭 演示数据：
- 智能情感识别（基于关键词）
- 预设哲学名言库
- 示例情感分析结果
- 完整的UI和用户体验

### 4. 技术栈展示

即使在演示模式下，项目也展示了完整的技术实现：

**后端技术**:
- Flask Web框架
- 语音处理（SpeechRecognition + FFmpeg）
- 图像生成（Pillow + Matplotlib）
- RESTful API设计

**前端技术**:
- 现代JavaScript (ES6+)
- Canvas音频可视化
- 响应式CSS设计
- WebRTC音频录制

**AI集成**:
- 多AI提供商支持架构
- 情感分析管道
- 文本生成和处理

## 为什么选择演示模式？

1. **即开即用**: 老师和teammate下载后立即可以体验所有功能
2. **功能完整**: 演示了项目的所有技术能力
3. **成本控制**: 避免API使用费用
4. **教学友好**: 适合课程作业展示和评估

## 从演示模式到生产模式

当需要真实AI功能时，只需：
1. 获取DeepSeek API密钥（$5免费额度）
2. 配置 `.env` 文件
3. 重启应用

即可获得：
- 真实情感分析
- 个性化哲学洞察
- 上下文相关回应
